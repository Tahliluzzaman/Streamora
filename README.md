# Streamora📺 Streamora

Your World of Live TV, All in One Place 🌍

Streamora is a modern, web-based IPTV player that helps users discover and watch live TV channels from different countries and categories through publicly available M3U playlists.

✨ Features

- 🌍 Country Filter — Explore channels by country.
- 🗂️ Category Filter — Browse channels by category.
- 🔎 Smart Search — Find channels quickly.
- ▶️ Live TV Player — Play supported streaming links directly in your browser.
- ❤️ Favorites — Keep your favorite channels handy.
- 🔄 Playlist Refresh — Reload playlists to retrieve updated channel and stream links.
- 📱 Responsive Design — Designed for mobile and desktop screens.
- 🌙 Modern Dark UI — Enjoy a clean, dark-themed interface.

📡 Playlist Sources

Streamora uses publicly available IPTV playlists provided by IPTV-org:

- All Channels: https://iptv-org.github.io/iptv/index.m3u
- By Country: https://iptv-org.github.io/iptv/index.country.m3u
- By Category: https://iptv-org.github.io/iptv/index.category.m3u
- Channel Metadata API: https://iptv-org.github.io/api/channels.json

Channel availability and playback depend on the original stream source, browser compatibility, and internet connection.
